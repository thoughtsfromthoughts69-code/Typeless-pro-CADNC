Startup Guide & Walkthrough
Mastering Typeless CAD AI

Welcome to Typeless CAD. This environment combines generative AI prompt engineering with high-performance Three.js 3D WebGL visualization and persistent Firebase component blocks.

01. Natural Language Prompting: Type any prompt in the Typeless Prompt tab (e.g., "radial turbine manifold") to synthesize runnable 3D code.
02. Component Block Shortcuts: Type / in the prompt bar to filter saved component blocks, or use /name [Block Name] to load saved parts.
03. Active Working Tools: Use the floating viewport tools (Select, Move, Rotate, Scale, Extrude, Wireframe Cut, Bevel, Decimate) to inspect and manipulate geometry.
04. Model Export: Export your 3D models instantly in STL, OBJ, GLB, or JSON format for CNC manufacturing or downstream CAD workflows.
